# Themes privacy policy

Last updated: 2026-11-25.

Themes (kit-themes) is a Claude Code plugin that gives the desktop and mobile apps a color theme. It runs entirely on
your own computer, inside Claude Code.

## What it reads

- Claude Code's own `language` setting, once at session start, only to choose English or Vietnamese for `/themes`.
- Its own saved choice (which theme), and its own plugin options.

It does not read your conversations, files, login or tokens.

## What it stores

One value, your theme choice, in the plugin's own storage inside Claude Code, written only when you use `/themes`.
Delete the plugin's storage or run `/themes auto` to reset it.

## Network and sharing

None. It makes no network requests and sends no data to anyone, including its authors.
